Вибери для кожного режиму групу індексів і потрібні значення. До режиму потраплятимуть лише картки, що мають хоча б один із вибраних тегів. Якщо нічого не вибрано — обмеження не діє.

Додавай держави, роки, фото, порядок та визначай, які показувати першими.

Масовий імпорт запитань з Excel

Завантаж таблицю .xlsx. Нові питання додадуться до каталогів, повтори будуть пропущені, а наявні записи не перезаписуватимуться.

Познач, які підрежими показувати відразу. Решта буде за кнопкою «Більше». Зміни зберігаються в цьому браузері.

Каталог запитань для обраної мінігри. Перемикай вкладки вище, щоб перейти до іншого каталогу.

Біографічні запитання вводяться вручну. Запитання про авторство створюються автоматично з індексу «Автор» у картках постатей.
У «Хто за фахом?» тут вказується постать, про яку сформульовано запитання. У «Хто з них» правильної постаті наперед немає: обидві картки формуються за індексом обраного фаху.

Кожне питання має власні теги держави, епохи та відповіді. У пошуку достатньо одного збігу: текст питання або будь-який тег. Теги відповіді можуть бути індексами чи іменами / ID постатей.

Експорт — резервна копія бази та локальної статистики. Імпорт додає записи до наявного каталогу; якщо ID збігається, запис оновлюється. У режимі адміністратора зміни синхронізуються з хмарою.

Фото оптимізуються та завантажуються в Supabase Storage. Якщо додано кілька — у грі випадково показуватиметься одне з них.

Індекси картки — спільні для всіх карток (значення через кому)

Лише для карток постатей. Вписуй по одному твору в рядок: книги, картини, музичні твори та інші роботи. З цього індексу автоматично формуються окремі запитання про авторство в мінігрі «Хто за фахом?». Підтримуються книги, картини, музичні твори, документи, технічні розробки та інші створені об’єкти.

Індекси вводяться через кому. Символ # додається автоматично; однакові індекси можна використовувати в багатьох картках. Гравцям індекси не показуються.
